<h1><ins>Final-Year Project</ins></h1>

<h1><ins>Obesity Prediction and Personalized Health Monitoring System</ins></h1>

The **Obesity Prediction and Personalized Health Monitoring System** is an AI-powered healthcare application designed to:

- Predict obesity levels
- Monitor calorie intake in real time
- Provide personalized health recommendations based on:
  - Lifestyle habits
  - Dietary patterns
  - Medical conditions

The project combines:

- Machine Learning
- Computer Vision
- Real-Time Monitoring
- Personalized Recommendation Systems

to create an intelligent and user-friendly healthcare assistant.

Unlike traditional obesity prediction systems that only classify users into categories such as **Normal**, **Overweight**, or **Obese**, this project goes beyond prediction by offering:

- Real-time calorie tracking
- Food image recognition
- BMI validation
- Personalized diet suggestions
- Personalized exercise recommendations
- Health-aware recommendations

This makes the system more practical, interactive, and suitable for real-world healthcare applications.

---

<h1><ins>Why We Built This Project</ins></h1>

Obesity has become one of the most serious global health challenges, leading to diseases such as:

- Diabetes
- Heart disease
- Hypertension
- Digestive disorders
- Lifestyle-related illnesses

Although many obesity prediction models already exist, most current systems suffer from major limitations, including:

- Lack of interpretability
- No real-time interaction
- Poor personalization
- Dataset bias
- Low adaptability

Most existing systems simply generate predictions without explaining:

- Why the prediction was made
- How users can improve their health

Our goal was to create a system that is:

- Intelligent
- Transparent
- Interactive
- Personalized
- Practical for everyday use

The project focuses not only on prediction accuracy but also on:

- Improving user trust
- Enhancing usability
- Delivering real healthcare value

<h1><ins>Research Gaps and Our Solutions</ins></h1>

---

<h1><ins>1. Lack of Interpretability in High-Accuracy Models</ins></h1>

<h2><ins>Research Gap</ins></h2>

Many modern obesity prediction systems use advanced deep learning models and automated machine learning pipelines.

Although these models provide high accuracy, they often behave like **black-box systems**, meaning:

- Users cannot understand how predictions are generated
- Healthcare professionals cannot easily interpret the results

This creates several challenges:

- Reduced trust in predictions
- Poor transparency
- Difficulty in clinical adoption
- Lack of explainability in healthcare environments

Healthcare applications require systems that can clearly explain their decisions.

---

<h2><ins>What We Did</ins></h2>

To solve this issue, we developed a **hybrid interpretable prediction framework**.

Our approach includes:

- Using a **Random Forest Classifier** instead of deep neural networks for:
  - Better transparency
  - Improved stability

- Integrating a **BMI-based validation layer**

- Displaying:
  - User lifestyle inputs
  - Dietary habits
  - Computed BMI value
  - BMI category
  - Final obesity prediction

This transformed the system into a **semi-explainable AI pipeline** where users can understand how their habits influence predictions.

---

<h2><ins>Impact</ins></h2>

- Improved user trust
- Better interpretability
- Increased healthcare usability
- More reliable decision-making system

---

<h1><ins>2. Absence of Real-Time Prediction Systems</ins></h1>

<h2><ins>Research Gap</ins></h2>

Most obesity prediction systems operate only in offline mode using:

- Static datasets
- Batch processing methods

These systems:

- Do not adapt to changing lifestyles
- Lack interactivity
- Cannot provide instant feedback
- Fail to monitor daily eating habits dynamically

As a result, users cannot continuously track or improve their health.

---

<h2><ins>What We Did</ins></h2>

We designed a fully interactive **real-time obesity monitoring system**.

<h3><ins>Key Features</ins></h3>

- Web-based user interface
- Instant obesity prediction
- Real-time food analysis using **MobileNetV2**
- Food image recognition
- Automatic calorie estimation
- Dynamic calorie tracking system
- Meal logging functionality
- Live calorie progress monitoring

The system continuously updates user intake and compares it against recommended calorie limits.

---

<h2><ins>Impact</ins></h2>

- Real-time health monitoring
- Better user engagement
- Dynamic lifestyle tracking
- Continuous health feedback

---

<h1><ins>3. Lack of High-Quality, Diverse, and Unbiased Datasets</ins></h1>

<h2><ins>Research Gap</ins></h2>

Many existing obesity prediction models rely on:

- Small datasets
- Limited demographic diversity
- Biased lifestyle patterns
- Non-generalizable health data

This reduces model performance across different populations and introduces prediction bias.

---

<h2><ins>What We Did</ins></h2>

To reduce dataset dependency and improve adaptability, we built a **data-agnostic adaptive framework**.

Our system combines:

- Machine learning predictions
- BMI-based physiological validation
- Real-time lifestyle inputs
- Dietary habits
- Physical activity levels
- Health condition analysis

Instead of depending only on static datasets, the system adapts dynamically using current user behavior.

---

<h2><ins>Impact</ins></h2>

- Reduced prediction bias
- Better generalization
- Improved adaptability
- More inclusive healthcare predictions

---

<h1><ins>4. Limited Personalization in Recommendations</ins></h1>

<h2><ins>Research Gap</ins></h2>

Most obesity prediction systems only provide classification outputs such as:

- Normal
- Overweight
- Obese

They fail to provide:

- Actionable guidance
- Personalized recommendations

This limits their real-world usefulness because users do not receive support on improving their health.

---

<h2><ins>What We Did</ins></h2>

We extended the system with a **multi-layered personalization engine**.

---

<h2><ins>Health-Aware Personalization</ins></h2>

The system considers medical conditions such as:

- Diabetes
- IBS (Irritable Bowel Syndrome)
- Gastric issues
- Constipation
- Food allergies

---

<h2><ins>Dietary Intelligence</ins></h2>

Using computer vision and calorie analysis, the system:

- Detects food items
- Estimates calorie values
- Identifies allergenic ingredients
- Detects unhealthy food patterns

It also provides:

- Real-time warnings
- Safer food alternatives
- Health-aware suggestions

---

<h2><ins>Exercise Personalization</ins></h2>

The system recommends exercises based on:

- Predicted obesity level
- User health conditions

<h3><ins>Examples</ins></h3>

- Low-impact workouts for IBS patients
- Cardio and strength exercises for obesity management

---

<h2><ins>Continuous Feedback Loop</ins></h2>

The platform continuously monitors:

- Daily calorie intake
- Meal history
- Progress tracking
- Adaptive health recommendations

---

<h2><ins>Impact</ins></h2>

- Highly personalized healthcare experience
- Better health management
- Actionable recommendations
- Increased practical usefulness
